# 📚 Ebook Library Platform

A modern, fast, and responsive digital ebook library web application built with **Laravel**, **React.js**, **Inertia.js**, and styled using **Tailwind CSS**.

---

## 🚀 Key Features

### 👤 User (Reader) Portal
- **Katalog Ebook Interaktif:** Telusuri seluruh koleksi buku lengkap dengan pencarian *real-time* dan filter kategori dinamis.
- **Dedicated Sidebar Layout:** Navigasi cepat dengan status link aktif, brand identity, dan kartu profil terintegrasi.
- **Embedded PDF Reader:** Membaca dokumen PDF langsung di dalam browser tanpa harus mengunduh file secara manual.
- **Personal Bookmark Collection:** Simpan dan kelola buku favorit ke koleksi pribadi hanya dengan satu klik.
- **Profil Akun & Kustomisasi:**
  - Ubah nama lengkap
  - Upload dan perbarui foto profil (avatar) dengan preview langsung
  - Ganti kata sandi dengan verifikasi keamanan
  - Manajemen sesi login & logout

### ⚡ Admin Management Panel
- **Statistik & Metrik Katalog:** Ringkasan total koleksi buku dan total kategori secara *real-time*.
- **Manajemen CRUD Lengkap:** Tambah, edit, perbarui, dan hapus ebook beserta sampul (*cover*) dan file dokumen PDF.
- **Proteksi Akses (Role-Based Access Control):** Pemisahan hak akses yang tegas antara pengguna biasa (*reader*) dan administrator.
- **Quick Action Tools:** Tombol akses cepat untuk kelola buku langsung dari kartu katalog admin.

## 🛠️ Tech Stack

- **Backend:** [Laravel](https://laravel.com/) (PHP)
- **Frontend:** [React.js](https://react.dev/) + [Inertia.js](https://inertiajs.com/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Database:** SQLite / MySQL
- **Storage:** Laravel Public Storage Disk (`storage:link`)
